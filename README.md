## 3. Математическая постановка

### Многозадачная функция потерь (Multi-Task Objective)
Совместная оптимизация взвешивает градиенты от обеих проекционных голов:
$$\mathcal{L}_{total} = \lambda_{\text{genre}} \mathcal{L}_{\text{genre}}(y_g, \hat{y}_g) + \lambda_{\text{century}} \mathcal{L}_{\text{century}}(y_c, \hat{y}_c)$$

Где для каждой задачи применяется сбалансированный **Focal Loss**:
$$\mathcal{L}_{\text{focal}}(p_t) = -\alpha_t (1 - p_t)^\gamma \log(p_t)$$
- $\gamma = 2.0$: Снижает вес легко классифицируемых частых примеров (Реализм, XIX век) и перенаправляет свыше 85% градиентов на редкие и сложные стили (Фовизм, Пуантилизм, XV век).
- $\alpha_t$: Обратно-пропорциональные веса частотности классов в обучающей выборке.

### Двухэтапная схема обучения (Curriculum Learning)
1. **Этап 1 (Прогрев голов):** Веса визуального бэкбона $\theta_{\text{backbone}}$ заморожены. Обучаются исключительно MLP-головы $\phi_{\text{genre}}$ и $\phi_{\text{century}}$ с высоким learning rate ($10^{-3}$) на протяжении 5 эпох.
2. **Этап 2 (Сквозное дообучение):** Размораживаются верхние сверточные стадии бэкбона. Вся модель обучается совместно с дифференциальными скоростями обучения ($\text{LR}_{\text{backbone}} = 2 \times 10^{-5}$, $\text{LR}_{\text{heads}} = 10^{-4}$) по расписанию `CosineAnnealingLR`.

## 4. Быстрый старт и запуск

### Шаг 1: Установка зависимостей
```bash
pip install -r requirements.txt
```

### Шаг 2: Запуск обучения через CLI
```bash
python train.py \
  --csv_path /path/to/classes.csv \
  --data_dir /path/to/wikiart_dataset \
  --backbone convnext_tiny \
  --img_size 224 \
  --batch_size 64 \
  --epochs_stage1 5 \
  --epochs_stage2 20 \
  --lr_stage1 0.001 \
  --lr_stage2_heads 0.0001 \
  --lr_stage2_backbone 0.00002 \
  --genre_weight 1.0 \
  --century_weight 0.8 \
  --use_focal_loss \
  --output_dir ./checkpoints
```

### Шаг 3: Запуск веб-приложения Streamlit
```bash
streamlit run app.py
```
Приложение доступно в браузере по адресу `http://localhost:8501`:
- **Библиотека шедевров**: Встроенные пресеты (Моне, Ван Гог, Да Винчи, Пикассо, Караваджо, Ротко) и загрузка любых картин пользователя.
- **Двуглавые метрики**: Совместный вывод Топ-1 Жанра и Топ-1 Исторического века с показателями уверенности.
- **Диаграммы распределения вероятностей**: Топ-N вероятных кандидатов на базе графиков Altair.
- **Интерактивные карты внимания Grad-CAM**: Переключение фокуса внимания («Жанр / Мазки» vs «Век / Композиция») и регулировка прозрачности наложения.
